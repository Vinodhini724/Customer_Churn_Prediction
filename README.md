# Customer Churn Prediction

A machine learning application that predicts customer churn using current-month customer behavior and produces next-month churn predictions.

## Key Outputs
- Churn probability
- Churn classification
- Customer risk segmentation
- ARPU-based analysis
- High-risk customer identification

## Technology
- Python
- Pandas
- NumPy
- Scikit-learn
- Joblib
- Streamlit

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```
